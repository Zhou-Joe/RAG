# En-Genie presentation video

Editable source for the 85-second, 1920 × 1080, 60 fps presentation. The story,
scene order and narration are in [v2_script.md](v2_script.md). The starting cut is
identified by [BASELINE.json](BASELINE.json), including its video checksum and
the hashes of the original source files.

Current review cut: **R2** adds **And more · Emails · images**, speeds up the male
prompt voice from 1.1 to 1.2, and moves the C-frame prompt click to the large
En-Genie icon at 0:32.4. At 0:57, **With En-Genie, no code, no setup, just ask**
keeps the original centered large words and the surrounding black code cards.
As the words appear, the cards fade away and the genie + Just ask fade in below
No setup on the same page. Quieter sound effects ease the transition. The film
remains 85 seconds long.

## What to edit

| File | Responsibility |
| --- | --- |
| `v2/film.py` | Scene boundaries, transitions, voice start times, captions and render driver |
| `v2/scenes_a.py` | Document storm, evidence answer, manuals, spreadsheets, cross-check, tracker and picture search |
| `v2/scenes_b.py` | Automation, Teams alert, weekly email and team/library network |
| `v2/scenes_c.py` | Brand introduction and 3D part view |
| `v2/common.py` | Drawing helpers, palette, typography and reusable sprites |
| `v2/narration.py` | Spoken lines, caption text, voice selection and speech synthesis |
| `v2/audio/vo_cues.json` | Recorded voice durations and captions; regenerated by narration.py |
| `v2/music.py` | Music editing and recovery from the earlier cut |
| `v2/mix.py` | Narration, music ducking, sound effects and loudness normalization |
| `v2/assets.py` | Prepared images from local PDFs, workbooks, photos and earlier footage |
| `v2/model3d/` | Headless capture of this app's Three.js Mine Train model |

## Local setup

The reference build uses macOS, Python 3.12, Avenir Next and SF Mono system
fonts, plus Homebrew FFmpeg at `/opt/homebrew/bin/ffmpeg`. The video environment
is separate from the Django app environment. Run the commands below from this
directory:

```sh
python3.12 -m venv v2_env
v2_env/bin/python -m pip install -r requirements.txt
```

Ask the video owner for the matching `video_collaboration_assets_R2.tar.gz` and extract it here:

```sh
tar -xzf /path/to/video_collaboration_assets_R2.tar.gz
```

The bundle supplies `v2/assets/` (including `assets.json` and 3D frames),
`v2/audio/vo/*.wav`, and `v2/audio/music_bed.wav`. These prepared inputs let you
render the current film without running Django, accessing its database, or
rebuilding documents. Keep the versioned `v2/audio/vo_cues.json` with the matching
voice recordings. Cue paths are relative to `v2/audio/` so every collaborator can
use their own checkout location.

Client documents, prepared images, recordings, model weights, rendered videos
and environments stay outside Git. The project's document-sharing rules apply
to the separate asset bundle. Rendering on another OS requires adapting the font
paths and collection indices in `common.py`, plus the FFmpeg path in the build
scripts; the macOS fonts are not included.

## Preview and render

Render a few frames near the scene you changed, then inspect the images:

```sh
v2_env/bin/python v2/film.py preview 11.6 18.6 35.9 40.5 66.6 77.5 80.5
v2_env/bin/python v2/film.py sheet 2
```

Previews go to `v2/preview/`. Build the silent film and soundtrack separately,
then combine them into a new output filename:

```sh
v2_env/bin/python v2/film.py render
v2_env/bin/python v2/mix.py
/opt/homebrew/bin/ffmpeg -n \
  -i v2/out/video_silent.mp4 -i v2/audio/final_mix.wav \
  -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -b:a 256k \
  -ar 48000 -ac 2 -t 85 -movflags +faststart \
  EnGenie_V2_85s_collaboration.mp4
```

The final command refuses to overwrite an existing file. Use a new output name
for each review cut. Check the resulting video, narration, captions and scene
transitions before calling a cut finished.

## Changing narration or regenerating inputs

For a line change, update `LINES` in `v2/narration.py`. Put the owner's matching
Kokoro files `kokoro-v1.0.onnx` and `voices-v1.0.bin` under `v2_deps/tts_models/`,
then regenerate just the changed line:

```sh
v2_env/bin/python v2/narration.py q_cross
```

Update `film.VO_START`, scene typing times and `film.WARPS` as needed. Some scenes
still animate on the original 75-second clock; `WARPS` maps their timing to the
85-second film. Re-render the frames and rebuild the audio mix after timing or
caption changes. Commit the new cue metadata along with the changed script and
share the matching WAV separately.

Optional full asset regeneration needs the original files under the app's
`media/documents/` and `data/doc_images/`, the `v2_source_review/chat_assets/`
images, and the earlier `Picture_first.mp4`, `Picture_middle.mp4` and
`Picture_end.mp4` in this directory. Run `v2/assets.py` only when intentionally
replacing the prepared assets. Rebuilding the music bed with `v2/music.py` needs
the earlier `final_mix_smooth.wav` and `narration_smooth.wav`; the two versioned
JSON files at this directory's root contain the timing metadata used for that
recovery.

The 3D capture reads this repository's `static/vehicle_tracker/` directly:

```sh
v2_env/bin/python v2/model3d/capture.py
```

Its Chromium headless-shell path is machine-specific; set `CHROME` in
`capture.py` to an installed binary before capturing. It replaces the existing
`v2/assets/model3d/` frames. The app does not need to be running.

## Working together

Use a branch per change and open a pull request. Coordinate edits to `film.py`
and narration timing, which affect multiple scenes. Include the changed
timecodes and reviewed preview frames or a review-cut location in the PR.
Update `v2_script.md` when the story or narration changes. Keep binary inputs
and review exports in the agreed separate asset location.

This directory is the shared source for future edits. The video owner's
original sibling `presentation_video/` workspace and verified full backup are
preserved separately. The initial published renderer keeps the baseline scene
code; packaging changes only locate the app from either directory layout and
make narration paths usable from other checkouts.
